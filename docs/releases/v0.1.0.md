# Picross Cubed v0.1.0

The first release of a 3D picross game for the browser: the sibling of the 2D
[Picross](https://github.com/austinthedeveloper/picross) web game, with its look, sounds
and settings.

## How it plays

Every puzzle is a block of cubes with a shape hidden inside. The number on a face counts
the cubes of the shape in the line running into that face: plain when they're together, a
circle for two pieces, a square for three or more. Break away everything that isn't the
shape and it's revealed in color.

## What's in it

- **17 original puzzles** from 3×3×3 to 7×5×7, each checked to have one answer you can
  reach without guessing
- **Break and Paint**, with strokes that keep to the layer they start on; drag empty space
  (or pick Turn) to turn the block, pinch or scroll to zoom
- **Peel** layers off the side facing you to see inside
- **Relaxed or Hearts** mode, three hints, undo/redo, reset, a timer that pauses in the
  background, best times and saved progress
- **Keyboard play** and screen-reader descriptions of every cube and its clues
- Light, dark and high-contrast themes, sound (off by default) and haptics
- **How to play**: the rules, then the first puzzle

## Under the hood

- A bitmask line solver for 3D clues; `npm run puzzles` picks which clues each puzzle
  hides and records its difficulty
- Shares its tokens, base styles, sound, haptics and helpers with the 2D game through
  `npm run sync:web` (see docs/shared-files.md)
- 41 unit tests, Playwright tests on a phone-sized screen, CI with a GitHub Pages deploy

## Play it

Play the latest `main` at https://austinthedeveloper.github.io/picross-3d/, or download `picross-cubed-v0.1.0.zip` below and serve the folder with any static file server
(`npx serve picross-cubed-v0.1.0`), or run it from source with `npm install && npm run dev`.
