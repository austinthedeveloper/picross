# Tier 1: Cast portraits

Shown in a 140 px circle on the dialogue stage (`src/ui/components/dialogue.ts`) and a
52 px circle in the run sign-off (`src/ui/screens/run/results.ts`). Replaces the
`portrait` emoji in `src/puzzles/scenes/*.json`.

Portraits are head-and-shoulders busts on a 48×48 grid, so they carry a little more
detail than the fight sprites. Compose them to sit inside a circle: nothing important in
the corners. Each character faces slightly toward the viewer, and all seven should read
as one cast: same line weight, same head size, same amount of shoulder.

The four speaking enemies (Curator, Forger, Gremlin, Tess) get a portrait here and a
fight sprite in 02-enemies.md. If a portrait fails, the sprite can stand in for it.

---
