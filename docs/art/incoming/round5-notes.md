# Round 5: chapters 4–7

Two candidates each for all six portraits in `06-cast-chapters-4-7.md` and all eighteen enemy forms in `07-enemies-chapters-4-7.md`: 48 PNGs total.

## References and continuity

The approved `public/art/cast/rook.png` and `tess.png` are style and scale references for the portraits. Their characters, symbols and backdrops are not part of the new briefs. Boss sprites use their same-numbered Mother Bramble, Ringmaster or Yeti portrait as a face reference. Each phase uses its same-numbered base sprite as a reference. Pick the same variant number across each set.

Only named phases with an explicit id in document 07 get new art: Wound-up Rex, Mother Bramble in Bloom, Showstopper and Avalanche Yeti. Other named phases keep the base sprite, as specified.

## Review priorities

- Portraits: circle fit, head scale, character props and expression; no background disc, scenery or symbols.
- Armored sprites: bold coral cracks that remain visible at 38 px.
- Wind-up bosses: a large yellow key; yellow restricted to the key except the explicitly allowed Rex gears.
- Clouds and gusts: as large as the body, with flat stepped shapes.
- Phase forms: same pose, identity and scale as the corresponding base, with only the described changes.

Open `round5-review.html` for paired previews on paper, dark surfaces and the dark page color. Portraits appear in 140 px dialogue circles and 52 px sign-off circles, with 40 px square previews. Enemies appear at 38 / 40 px and enlarged, plus portrait-to-sprite and base-to-phase comparisons.

## Files and cleanup

Exact submitted prompts and image references are in `round5-manifest.json`, together with file hashes, PNG dimensions, transparency measurements and per-candidate observations. The generator is the built-in image_gen tool.

Prompts request 48×48 cells for portraits and 32×32 for sprites. Native stepped grids are retained per the accepted policy; these counts are requests, not measured results. Native PNG resolution and generated alpha are preserved. There is no trim, resize, palette cleanup or installation in this round; those remain with the project owner. Earlier incoming files are preserved. Optional chapter banners remain deferred.
